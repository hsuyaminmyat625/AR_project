# AR Runner UI

An iOS SwiftUI prototype for an AR-assisted running experience.

## Project layout

The Xcode app is located in `AR_Runner_UI/`:

- `App/` — app entry point and top-level navigation
- `Core/` — shared UI, location permission UI, and Unity integration
- `Features/` — screens grouped by user-facing feature
- `Resources/` — asset catalogs
- `Documentation/` — setup and integration notes

Open `AR_Runner_UI/AR_Runner_UI.xcodeproj` in Xcode to run the app.
